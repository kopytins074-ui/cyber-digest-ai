# ИИ-сервис подготовки новостного дайджеста по кибербезопасности

Прототип сервиса, который автоматически собирает новости по кибербезопасности, фильтрует их, объединяет сообщения об одном событии, выбирает топ-5 самых важных и формирует дайджест для рассылки и пост для соцсетей.

## Что делает проект

1. **Фильтрует новости по времени** — оставляет только за последние 24 часа (московское время).
2. **Фильтрует по теме** — с помощью ИИ определяет, относится ли новость к кибербезопасности.
3. **Объединяет дубликаты** — с помощью ИИ группирует новости об одном событии.
4. **Отбирает топ-5** — с помощью ИИ выбирает 5 самых важных событий по критериям масштаба, последствий и срочности.
5. **Генерирует текст** — с помощью ИИ пишет заголовок, суть и последствия для каждого события.
6. **Валидирует** — проверяет, что ИИ не выдумал числа, которых нет в источниках.
7. **Формирует результат** — создаёт дайджест (`digest.json`), предпросмотр письма (`email_preview.txt`) и пост для соцсетей (`post.txt`).

## Технологии

- **Python 3.13** — язык разработки.
- **Cloud.ru Foundation Models** — API для доступа к ИИ (модель `deepseek-ai/DeepSeek-V4-Flash`).
- **Библиотека `openai`** — для работы с API.

## Требования

- **Python 3.10 или выше**.
- **API-ключ Cloud.ru** (нужно получить на платформе Cloud.ru).
- **Файл `news.json`** с новостями (организаторы предоставляют его отдельно).
